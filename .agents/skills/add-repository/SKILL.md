Read [the guided workflow](../../../core/setup/install.md) and follow “Adding one
repository”. Limit work to the repository and tools the person selects; support
gate-only adoption. Reruns reconcile existing state safely. Never ask for or
accept tokens in chat.

Gate-only adoption needs only Node, git and authenticated gh; the Mac/desktop-app requirement applies to local tools and their schedule.
